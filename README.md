# GBZapCleaner
TiWorker.exe Virus Remover -> (9bd6d3998c1c8a9c173b6eab19819ada9cc88a87f77b4c9e96b8f4d8c0d38279)
GBZapCleaner v2.0
=================

Целевая защитная утилита для поиска образца TiWorker.exe, переданного на анализ,
и близких вариантов по семейным маркерам/эвристике.

ВАЖНО
-----
• Сканирование само по себе НИЧЕГО не удаляет.
• После сканирования программа показывает полный список найденных файлов.
• Удаление выполняется только после явного выбора и второго подтверждения [y/N].
• Режим C выбирает только находки уровня CONFIRMED.
• HIGH/SUSPICIOUS требуют ручного выбора через режим S или A.
• Утилита не запускает найденные EXE.

Основная сигнатура вредоносного образца:
SHA-256:
9bd6d3998c1c8a9c173b6eab19819ada9cc88a87f77b4c9e96b8f4d8c0d38279
Размер: 3 592 990 байт

Дополнительные признаки:
• GBZAP-PACK-UNIQUE
• GBZAPUNQ2
• связка zapRETDiscORd + flowseal
• подозрительная комбинация: имя TiWorker + Hidden/System + UPX вне WinSxS

Уровни:
CONFIRMED  — точный SHA-256 или уникальный семейный маркер.
HIGH       — сильная связка семейных маркеров; не удаляется режимом C.
SUSPICIOUS — только консервативная эвристика; удалять лишь после проверки.

Защита штатного Windows TiWorker:
• WinSxS исключён из эвристического полного сканирования.
• Обычный штатный TiWorker не считается вредоносным по одному имени.
• Для автоматического выбора C нужны точный вредоносный хэш или уникальные маркеры.

Удаление:
1. Снимаются атрибуты Hidden / System / Read-only.
2. Выполняется обычное удаление.
3. Если мешают ACL — takeown + icacls, затем повтор удаления.
4. Если файл занят — ставится удаление на следующую перезагрузку Windows.

Запуск:
1. Используйте GBZapCleaner_v2_x64.exe для обычной Windows 10/11 x64.
2. Программа сама предложит запросить права администратора через UAC.
3. Выберите:
   1 — быстрое сканирование;
   2 — полное сканирование локальных дисков;
   3 — конкретный путь.
4. После сканирования изучите список находок.
5. Выберите C / S / A / N.
6. Подтвердите удаление через y.

Аргументы командной строки:
  GBZapCleaner_v2_x64.exe --quick
  GBZapCleaner_v2_x64.exe --full
  GBZapCleaner_v2_x64.exe --root "C:\Users\name\Desktop"
  GBZapCleaner_v2_x64.exe --no-color

Лог создаётся на рабочем столе с именем вида:
GBZapCleaner_YYYYMMDD_HHMMSS.log
